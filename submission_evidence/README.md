# Lab 07 - Evidence

This folder contains selected evidence for the Day 07 report.

- benchmark/: 24 DEV/TEST questions and evidence labels
- retrieval/: retrieval summaries and TEST comparison
- agent/: reduced traces and provisional DEV/TEST metrics
- audit/: keyword-based checks for unanswerable cases

The metrics are based on human-reviewed answer and citation
labels. Abstention correctness remains provisional because
corpus-wide manual confirmation has not been finalized.

Reduced traces omit full context text and local absolute paths.
Full traces are preserved locally under starter/results/.

The PDF, ChromaDB database, embedding model, API keys and
local environment are not included in this evidence package.
